دليل الاستخدام

تعرف على أقسام التطبيق وكيفية استخدامها

لوحة التحكم

الصفحة الرئيسية للتطبيق، تعرض لك ملخصاً سريعاً عن:

  • 📊 إجمالي العروض المحفوظة
  • 👥 عدد العملاء المسجلين
  • 🔧 إجمالي المعدات في العروض
  • 💰 إجمالي الإيرادات المتوقعة

صفحة العرض

هنا تقوم بإنشاء عروض الأسعار وإدارتها:

  • ➕ إضافة بنود المعدات بسهولة
  • 📝 تحديد نوع السعر (يومي/شهري)
  • ⏱️ اختيار المدة (ساعات/أيام/شهور)
  • 🧮 حساب الإجمالي تلقائياً
  • 📄 تصدير PDF أو Excel
  • 💾 حفظ العروض للرجوع إليها
  • 📋 إضافة ملاحظات وشروط
  • 🔒 النسخة المجانية: 3 بنود فقط
  • ⭐ النسخة المدفوعة: بنود غير محدودة

بيانات الشركة

إدارة معلومات شركتك:

  • 🏢 اسم الشركة، الهاتف، العنوان
  • 🆔 السجل التجاري والرقم الضريبي
  • 🖼️ رفع شعار الشركة
  • ✍️ إضافة التوقيع الإلكتروني (مدفوع)

التقارير

تحليل أداء العروض والإيرادات (متاح في النسخة المدفوعة):

  • 📈 إحصائيات العروض
  • 📊 رسوم بيانية
  • 📋 قائمة العروض مع الفلترة
  • 📤 تصدير التقارير

التصميم

تخصيص مظهر التطبيق:

  • 🎨 تغيير الألوان الأساسية
  • 🖋️ اختيار الخط المناسب
  • 🌙 التبديل بين الوضع الفاتح والغامق
  • 🔣 اختيار أيقونات المعدات

الترقية والاشتراك

للاستفادة من جميع الميزات:

  • 📅 اشتراك شهري: 99 ج.م
  • 📆 اشتراك سنوي: 499 ج.م (وفر 50%)
  • 🔓 بنود وعروض غير محدودة
  • 📊 التقارير والإحصائيات
  • ✍️ التوقيع الإلكتروني
  • 🎨 تخصيص كامل
ترقية الآن

اختصارات لوحة المفاتيح

  • Ctrl + N إضافة بند جديد
  • Ctrl + S حفظ العرض
  • Ctrl + P تصدير PDF
  • Ctrl + E تصدير Excel
  • Ctrl + Shift + P معاينة العرض
