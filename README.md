# نظام عروض أسعار المعدات

نظام متكامل لإدارة عروض أسعار إيجار المعدات الثقيلة، مبني بتقنيات الويب الحديثة ويعمل كـ PWA.

## ✨ الميزات

- **إدارة العروض**: إنشاء وتحرير وحذف عروض الأسعار
- **إدارة العملاء**: إضافة وتعديل وحذف بيانات العملاء
- **التقارير**: عرض إحصائيات ورسوم بيانية للعروض والإيرادات
- **التخصيص**: تغيير الألوان والخطوط والأيقونات
- **التصدير**: تصدير العروض بصيغ PDF و Excel
- **PWA**: يعمل كتطبيق مستقل على الهواتف والأجهزة
- **وضع ليلي/نهاري**: دعم كامل للمظهرين
